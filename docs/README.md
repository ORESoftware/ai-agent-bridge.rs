# docs

Long-form documentation for the ai-agent-bridge service. The repo root
`README.md` is the overview; deeper protocol material lives here.

- `agents-guide.md` — the complete protocol reference for both transports
  (HTTP REST + SSE and TCP JSONL): concepts, every operation and message shape,
  common recipes, and a copy-paste instruction block that can be dropped into an
  AI agent's system prompt so Claude or Codex knows how to use the bus.
